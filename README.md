Esse projeto, iniciado no fim de 2024 e início de 2025, tem como objetivo, simular as divisões dos campeonatos de futebol do Brasil, que atualmente vai até a quarta divisão (sérieD).
Foram resgatados um pouco mais de 800 clubes considerados ativos das 27 UF's. A tentativa é de proporcionar a clubes pequenos um calendário mais estenso no futebol para além das copas e campeonatos estaduais e regionais.
Por se tratar de dados de 2024/2025, é possível que algumas informações estejam inconsistentes, como o número de clubes por federação. Porém, ao utilizar esse arquivo como base, se torna mais prático atualizar de acordo com as demandas. 
Os resultados prévios apontam para a criação de mais 6 divisões (Série J), sendo que a partir de determinada divisão, as competições se tornem regionais.
